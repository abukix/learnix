# Code of Conduct

`learnix` adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

The full text is available at the link above.

## In short

- Be kind. Disagree on substance, never on personality.
- Assume good faith.
- Focus on the work.
- Own mistakes; move on.

## Scope

Applies wherever `learnix` is represented:

- This GitHub repository (Issues, PRs, Discussions)
- Any public conversations where you identify as a contributor

## Reporting

- **Not urgent, not private:** open a [GitHub Discussion](https://github.com/abukix/learnix/discussions) tagged `conduct`
- **Private:** email `me@abukix.dev`

Reports are handled confidentially. Response commitment: acknowledgment within 72 hours; investigation within 2 weeks.

## Enforcement

Per Contributor Covenant 2.1's ladder, proportional to severity:

1. **Correction**: private written notice.
2. **Warning**: formal warning with consequences noted.
3. **Temporary ban**: defined period, no interaction.
4. **Permanent ban**: no further participation.

Solo-maintainer decision is final.

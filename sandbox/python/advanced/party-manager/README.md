# Party Manager

Restarted from scratch on 2026-08-21, alongside a full re-review of the boot.dev Python course — see [`topics/python/notes/python-basics.md`](../../../topics/python/notes/python-basics.md) and [`python-cheatsheet.md`](../../../topics/python/notes/python-cheatsheet.md).

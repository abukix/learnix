# learnix

Backend engineering notes, written in my own words and organized for technical interview preparation.

## Purpose

Notes copied from a course are quick to produce and difficult to review. Each note in this repository explains a concept in plain language, shows working code, compares the idea across languages, and ends with the questions an interviewer is likely to ask.

## Structure

```
learnix/
├── _TEMPLATE.md        Format used by every chapter note
└── backend-path/
    ├── 01-python/      Primary language
    └── 02-linux/
```

- One folder per course and one file per chapter, numbered to match the course.
- Notes are organized by concept rather than by lesson. Course-specific stories and exercises are left out so each note stands on its own.
- Every chapter follows `_TEMPLATE.md`: What it is, Analogy, Example, In other languages, Interview framing, My answer, and Follow-up gotchas.

## Conventions

- One commit per chapter note or study session.
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/), for example `docs(python): add chapter 2 note`.
- Commits use real dates with no backdating. The journal starts on 2026-10-01.

## Key takeaways

- Python is high-level, interpreted, and used heavily for AI/ML, automation, and backend web dev (Django, Flask).
- Syntax errors come from missing symbols, typos, unclosed strings, or bad indentation.
- Variables store reusable, changeable data; Python convention is `snake_case` naming.

# Contributing to learnix

`learnix` is a personal learning-in-public archive. Contributions welcome, with intentional scope limits.

## What's welcome

| Contribution | Welcome? |
|---|---|
| **Typo / grammar fixes in notes** | Yes, open a PR directly |
| **Broken-link repairs** (course URLs that moved, dead resource pages) | Yes |
| **Factual corrections** (a certification's cost changed, a course was rewritten, a resource I mis-summarized) | Yes, include a source |
| **Adding new topic notes** | Not accepting. This is a personal journal, not a wiki |
| **Adding new resource reviews** | Not accepting. Ratings are one operator's opinion |
| **Adding new certification tracks** | Not accepting. Only certs I've personally chased |

## How to contribute

1. Fork this repo.
2. Branch off `main`: `git checkout -b fix/typo-in-linux-notes`.
3. One concern per PR.
4. Commit with a clear message.
5. Open the PR against `main`.

Response time: best-effort, solo maintainer. Typo fixes usually merge within a week.

## Voice

If you're editing prose:

- Direct, no hedge-words ("might", "perhaps", "you may want").
- No marketing language ("industry-leading", "cutting-edge", "revolutionary").
- Honest about what worked and what didn't.
- Cite sources for factual claims.

## Contact

- **Questions / discussion:** open a [GitHub Discussion](https://github.com/abukix/learnix/discussions)
- **Bug (broken link, factual error):** open an [Issue](https://github.com/abukix/learnix/issues)
- **Direct:** `me@abukix.dev`

Thanks for considering a contribution. Even a typo fix is meaningful.
